# Living-LAB_website

Living Lab web application built with React and Vite, integrated with the Liv App backend APIs.

## Tech Stack
- React 18
- Vite
- Liv App Backend APIs (Reports, Patient Profile, Care Plan)
- Firebase Authentication

## Getting Started

### 1. Install dependencies
```bash
npm install
```

### 2. Configure Environment Variables
Copy `.env.example` to `.env` and configure your API base URLs:
```bash
cp .env.example .env
```

### 3. Run development server
```bash
npm run dev
```

### 4. Build for production
```bash
npm run build
```
